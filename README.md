# plan_estudio_tech

Aprender 7 herramientas para un perfil AI Builder, con una línea por herramienta.

## Objetivo
Del 22 al 28 de octubre de 2026 pruebo una herramienta distinta cada día, viendo material y construyendo algo funcional con cada una. Vengo de un perfil de negocio y quiero entender qué ofrece cada herramienta, cuándo usarla y qué límites tiene.

## Herramientas
- **Día 1 · GitHub + Copilot:** control de versiones, ramas y pull requests, y un asistente de IA Copilot para preguntar por el código.
- **Día 2 · Cursor:** editor con IA para crear una mini-app y revisar los cambios antes de aceptarlos.
- **Día 3 · Claude Code:** repetir el ejercicio con Claude Code y comparar con Cursor.
- **Día 4 · MCP y Skills:** conectar herramientas a la IA y crear instrucciones reutilizables.
- **Día 5 · Dust:** crear un agente que responda con documentación propia.
- **Día 6 · Power Platform:** una app en Power Apps y un flujo en Power Automate.
- **Día 7 · Copilot Studio:** un agente con una fuente de conocimiento que también sepa decir que no lo sabe.

## Día 1: GitHub + Copilot

**Qué practiqué**
- Creé este repositorio.
- Creé una rama y practiqué commits.
- Hice un fork de un repositorio de ejemplo y abrí pull requests.

**Qué aprendí**
- La diferencia entre Git y GitHub.
- Qué son un repositorio, una rama, un commit, un pull request y un fork.
- Que bitbucket es como github pero de Atlassian.
- Que Github - Copilot se instala en Visual Studio Code o JetBrains pero como no uso editores de código lo quise probar directamente en Github web.

**Qué falló**
- No pude probar el chat de Copilot en GitHub.com. Al abrirlo me salió una ventana de bienvenida que daba el error "We could not save your guided setup. Please try again." y no me dejó seguir.
- Lo repetiré más tarde.
